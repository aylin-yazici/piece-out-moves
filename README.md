# Piece Out! (moves version)

D0 test build of Piece Out!, a slice-sorting puzzle game. This is the **moves version**: there is no timer and no lives. Each tap uses one move, and running out of moves is the only way to fail.

- 60 levels, each with 44-55 moves (the puzzle levels have 12-15)
- A tap on the wrong plate also costs a move
- No combos

Play: https://aylin-yazici.github.io/piece-out-moves/

The earlier timer + lives version is at https://aylin-yazici.github.io/piece-out/
